# Tony's Kitchen – คำนวณโสหุ้ย (Overhead Calculator)

แอปพลิเคชันเว็บคำนวณสัดส่วนค่าใช้จ่ายโสหุ้ยดำเนินงาน (**Overhead % of Selling Price**) เทียบกับราคาขายก่อน VAT สำหรับร้านอาหารไทยขนาดกลางและร้านเปิดใหม่ ใช้งานฟรี 100% ทำงานแบบออฟไลน์ ไม่ต้องต่อฐานข้อมูลภายนอก ข้อมูลทั้งหมดถูกจัดเก็บไว้ในเบราว์เซอร์ของอุปกรณ์คุณเท่านั้น

---

## 🎯 วัตถุประสงค์ของแอป
ช่วยให้เจ้าของร้านอาหารสามารถคำนวณหาตัวเลข **"% โสหุ้ยที่แนะนำ"** ที่แม่นยำ เพื่อนำไปพิมพ์ใส่ในโปรแกรมหรือสเปรดชีตคำนวณต้นทุนอาหาร (**Food Cost App**) ของตนเองได้ทันที แม้ว่า:
1. ร้านจะเพิ่งเปิดใหม่ ยังไม่มีประวัติยอดขายจริงในอดีต (มีระบบประมาณการจากจำนวนที่นั่งและรอบโต๊ะ)
2. เจ้าของร้านไม่มีเวลาบันทึกยอดขายแยกรายเมนู (ใช้เพียง **ยอดขายรวมวันละ 1 ตัวเลข** ตอนปิดร้าน)

## ⚠️ คำเตือนเรื่องการจัดเก็บข้อมูล (Data Persistence Notice)
- ข้อมูลทั้งหมด (ค่าใช้จ่าย สินทรัพย์ และยอดขาย) บันทึกอยู่ใน **LocalStorage** ภายในเบราว์เซอร์ของอุปกรณ์นี้เท่านั้น
- การล้างประวัติการท่องเว็บ (Clear Browsing Data / Cache) หรือการเปลี่ยนเครื่อง จะทำให้ข้อมูลสูญหายได้
- **คำแนะนำ:** หมั่นกดปุ่ม **"Export ข้อมูล (JSON)"** ในแท็บ **"ตั้งค่า"** เพื่อดาวน์โหลดไฟล์สำรองเก็บไว้ในเครื่องคอมพิวเตอร์หรือโทรศัพท์ของคุณเป็นประจำ

## 🚀 ฟีเจอร์หลัก (Key Features)

1. **สรุปผล (% Overhead แนะนำ):**
   - แสดงตัวเลขแนะนำชัดเจน เช่น `35.0% ของราคาขาย (ก่อน VAT)` พร้อมปุ่มคัดลอกตัวเลขทันที
   - ประโยคตัวอย่างสำหรับเจ้าของร้าน: *"ถ้าเมนูขาย 100 บาท จะมีต้นทุนโสหุ้ยแฝง X บาท"*
   - ตารางเปรียบเทียบสัดส่วนโสหุ้ยตาม 3 ฐานยอดขาย (ประมาณการร้านใหม่ / กรอกรายเดือนเอง / ยอดขายจริง)
   - คำนวณยอดขายจุดคุ้มทุน (Break-even) และยอดขายเพื่อให้ได้กำไรเป้าหมาย ทั้งต่อเดือนและต่อวัน
   - ตารางวิเคราะห์ความอ่อนไหว (Sensitivity Analysis) ที่ยอดขาย 70%, 100%, 130%, 150%
   - สรุปสัดส่วนค่าใช้จ่ายแยก 8 หมวดหมู่ พร้อมแท่งกราฟ CSS Bar
   - ระบบแจ้งเตือนอัจฉริยะ (เมื่อโสหุ้ย > 50%, ลืมใส่เงินเดือนเจ้าของ, หมวดค่าใช้จ่ายเป็น 0, สำรองข้อมูลเกิน 7 วัน)

2. **รายการค่าใช้จ่าย 8 หมวดหมู่มาตรฐาน:**
   - 1. ที่และอาคาร
   - 2. ค่าแรง
   - 3. สาธารณูปโภค
   - 4. ของใช้สิ้นเปลือง
   - 5. ซ่อมบำรุงและความสะอาด
   - 6. การขายและการตลาด
   - 7. ธุรการ กฎหมาย การเงิน
   - 8. ค่าเผื่อความสูญเสีย (% ของยอดขาย)
   - ปรับความถี่ได้ (ต่อเดือน / ต่อสัปดาห์ / ต่อวัน / ต่อไตรมาส / ต่อปี / % ของยอดขาย)
   - มีช่องติ๊ก *"ไม่นับ (ใส่ในสูตรรายจานแล้ว)"* สำหรับต้นทุนแฝงที่ใส่ในสูตรแล้ว เพื่อป้องกันการคิดซ้ำซ้อน
   - แผงความรู้: **"อะไรที่ห้ามนับในโสหุ้ยเด็ดขาด"** (10 ข้อสำคัญ)

3. **ค่าเสื่อมราคาและผ่อนอุปกรณ์ (Assets):**
   - รองรับทั้งการตัดค่าเสื่อมราคาตามอายุการใช้งาน และการบันทึกค่างวดผ่อนต่อเดือน
   - ปุ่มลัดเพิ่มอุปกรณ์มาตรฐาน (เตาแก๊ส, ตู้แช่, แอร์, โต๊ะเก้าอี้, ป้ายร้าน, POS)

4. **ยอดขาย (3 ฐานการคำนวณ):**
   - **ประมาณการร้านใหม่:** ที่นั่ง × รอบหมุนต่อวัน × ยอดใช้จ่ายเฉลี่ยต่อหัว × วันเปิดทำการ
   - **กรอกยอดขายต่อเดือนเอง:** กำหนดเป้าหมายรายเดือนโดยตรง
   - **บันทึกยอดขายรวมรายวัน:** กรอกเพียงตัวเลขเดียวต่อวัน อัปเดตเฉลี่ย 7 / 14 / 30 วันอัตโนมัติ มีคำแนะนำหายอดรวมใน 30 วินาที
   - รองรับการติ๊กยอดขายรวม VAT แล้ว เพื่อถอด VAT ออกเป็นฐานก่อน VAT เสมอ

5. **ตั้งค่า & สำรองข้อมูล (Backup & Restore):**
   - ปรับชื่อร้าน จำนวนวันเปิดทำการ อัตรา VAT เปอร์เซ็นต์ Food Cost และกำไรเป้าหมาย
   - Export ข้อมูลเป็นไฟล์ JSON (`tonys-kitchen-overhead-backup-YYYY-MM-DD.json`) พร้อมฟิลด์ `overheadPercentOfSales`
   - Import ไฟล์ JSON พร้อมระบบตรวจสอบโครงสร้าง ป้องกันไฟล์เสียหาย
   - โหลดข้อมูลตัวอย่างร้านอาหารขนาดกลาง และรีเซ็ตเป็นแบบฟอร์มเปล่า

## 💻 การติดตั้งและรันในเครื่อง (Local Development)

### ข้อกำหนด:
- Node.js version 20 ขึ้นไป
- npm

### ขั้นตอน:
```bash
# 1. ติดตั้ง Dependencies ทั้งหมด
npm install

# 2. เริ่มต้น Development Server
npm run dev
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

### การทดสอบ Build:
```bash
npm run build
```

## 🌐 ขั้นตอนการ Deploy ขึ้น GitHub Pages ฟรี (Step-by-Step)

แอปพลิเคชันนี้ถูกตั้งค่าให้พร้อม Deploy ขึ้น GitHub Pages ผ่าน **GitHub Actions** ทันทีโดยไม่ต้องเขียนโค้ดเพิ่ม:

1. **สร้าง Git Repository ใหม่บน GitHub:**
   - เข้าที่ [github.com/new](https://github.com/new)
   - ตั้งชื่อ Repository เช่น `tonys-kitchen-overhead`
   - เลือกสถานะเป็น **Public**
   - กด **Create repository**

2. **Push โค้ดขึ้น GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial release of Tony's Kitchen Overhead Calculator"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
   git push -u origin main
   ```

3. **เปิดใช้งาน GitHub Pages ในการตั้งค่าของ Repository:**
   - ไปที่แท็บ **Settings** ของ Repository บน GitHub
   - เลือกเมนูด้านซ้าย **Pages**
   - ในหัวข้อ **Build and deployment** > **Source** ให้เปลี่ยนเป็น **GitHub Actions**
   - Workflow ในไฟล์ `.github/workflows/deploy.yml` จะทำงานอัตโนมัติ

4. **เปิดใช้งานแอป:**
   - เมื่อ Workflow ทำงานเสร็จสิ้น (ประมาณ 1 นาที) จะปรากฏลิงก์ของเว็บไซต์ เช่น:
     `https://<YOUR_USERNAME>.github.io/<REPO_NAME>/`
   - สามารถเปิดใช้งานได้จากคอมพิวเตอร์ แท็บเล็ต หรือมือถือได้ทันที

## 📐 การตัดสินใจทางสถาปัตยกรรม (Design & Architectural Decisions)
1. **การถอด VAT ออกจากฐานยอดขาย:** ในกรณีที่เจ้าของร้านติ๊กเลือกว่า *"ตัวเลขยอดขายที่กรอก รวม VAT แล้ว"* ระบบจะหารยอดขายด้วย `(1 + vatRate / 100)` เสมอ เพื่อให้ตัวเลขยอดขายเป็นฐานก่อน VAT ก่อนนำมาหารโสหุ้ยคงที่ ทำให้ได้สัดส่วน % โสหุ้ยที่ถูกต้องตามหลักบัญชีร้านอาหาร
2. **การรวมค่างวดอุปกรณ์และค่าเสื่อมราคา:** ในหน้าสรุปผล สัดส่วนค่าเสื่อมราคาและค่างวดผ่อนถูกจัดรวมเข้าเป็นหมวดหมู่ที่ 9 *"ค่าเสื่อมราคาและผ่อนอุปกรณ์"* เพื่อให้เห็นภาพชัดเจนแยกจากค่าใช้จ่ายดำเนินการปกติ
3. **การ Upsert ข้อมูลยอดขายรายวัน:** หากบันทึกยอดขายซ้ำวันที่เดิม ระบบจะอัปเดตยอดของวันนั้นแทนการสร้างแถวซ้ำซ้อน เพื่อป้องกันข้อมูลผิดพลาด
